# 🐾 **Homeless Animals Analysis**

## 📌 **Project Overview**
The **Homeless Animals Analysis** project aims to explore and analyze data on homeless animals. This project provides insights into trends, causes, and potential solutions for improving the welfare of homeless animals.

## 📊 **Dataset**
The project includes the following datasets:
- `homelessanimals.csv` - *Raw dataset containing information about homeless animals.*
- `cleaned_dataset.csv` - *Preprocessed dataset after cleaning and transformation.*

## 📖 **Analysis & Insights**
The analysis focuses on:
- 🐕 **The distribution of homeless animals** by species and breed.
- 📈 **Trends over time** in animal shelter admissions.
- 🏡 **Factors affecting the likelihood of adoption.**
- 🗺️ **Geographic patterns** of homeless animals.
- 🏠 **Correlation between shelter capacity and adoption rates.**

## ⚙️ **Technologies Used**
- **Python** (`Pandas`, `NumPy`, `Matplotlib`, `Seaborn`)
- **Jupyter Notebook** for data analysis
- **CSV files** for dataset storage

## 📂 **Repository Structure**
```
Homeless-Animals-Analysis/
│-- Homeless_Animals.ipynb     # Jupyter Notebook with analysis
│-- homelessanimals.csv        # Raw dataset
│-- cleaned_dataset.csv        # Processed dataset
│-- README.md                  # Project description
```

## 🚀 **How to Use**
1. **Clone the repository:**
   ```sh
   git clone https://github.com/scarblase/Homeless-Animals-Analysis.git
   ```
2. **Open Jupyter Notebook** and run `Homeless_Animals.ipynb` to explore the analysis.
